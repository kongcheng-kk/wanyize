这个页面做了什么

  1. fetch(URL) 发起 GET 请求，拿到 Response 对象。
  2. res.ok 为假时抛出错误（如 404 / 500），交给 catch 统一处理。
  3. res.json() 把响应体解析成 JS 对象，商品数组在 data.products 里。
  4. 遍历数组拼 HTML，插入 #wan_list 容器完成渲染。
  5. 每个卡片是 <a href="17-3-detail.html?id=…">，用查询字符串把商品 ID 传给详情页。
