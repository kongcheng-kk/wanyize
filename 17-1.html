一、什么是 JSON

JSON（JavaScript 对象表示法）是一种纯文本格式的数据交换语言。它诞生于 JavaScript 的对象写法，但如今已经是独立于语言的通用标准：服务器返回数据、配置文件、接口传输，几乎都用它。

轻量纯文本、结构紧凑，比 XML 更小更快
易读键值对结构，人和机器都容易理解
通用所有主流语言都有解析与生成库

二、JSON 语法规则

  • 1数据写在名称 / 值对中：名称就是带双引号的字符串，中间用冒号，如 "wan_name": "万逸泽"
  • 2多个数据之间用逗号分隔，最后一项后面不能再加逗号
  • 3花括号 {} 保存对象，方括号 [] 保存数组，两者可以任意嵌套
  • 4JSON 里不允许出现注释、函数、undefined，字符串只能用双引号

JSON 值的六种类型

类型写法示例说明
字符串"hello"必须用双引号包裹，不能用单引号
数字329.5整数或小数，不能加引号
布尔值true / false全小写，不是 True
空值null表示「没有值」
对象{"wan_id": 1}花括号包裹的键值对集合
数组[1, 2, 3]方括号包裹的有序列表

三、JSON 与 JavaScript 对象的区别

JSON 本质是一段字符串；JS 对象是内存里真实存在的对象。两者长得像，规则却不同：

对比项JSONJavaScript 对象
本质字符串（文本格式）内存中的对象
键名必须加双引号可以不加引号
值的类型只有右边六种任意类型，包括函数、undefined
注释不允许允许 // 与 /* */
末尾逗号不允许允许
单双引号字符串只能双引号单双引号都可以

五、JSON.parse —— 把 JSON 字符串变成 JS 对象

接口返回的数据一开始都是字符串，必须先 JSON.parse() 才能当对象用。

示例：解析一段用户信息 字符串 → 对象

{"wan_name":"万逸泽","wan_stuId":24001010412,"wan_city":"武汉","wan_skills":["HTML","CSS","JavaScript"],"wan_isVip":true,"wan_motto":null}
var wan_user = JSON.parse(wan_jsonText);   // 字符串 → 对象
字段解析出的值

如果字符串不符合 JSON 语法，JSON.parse 会直接抛出异常，实际开发中要配合 try…catch 使用。

六、JSON.stringify —— 把 JS 对象变成 JSON 字符串

提交数据给服务器前，要把对象序列化成 JSON 字符串。第二个参数传 null，第三个参数控制缩进空格数。

var wan_jsonStr = JSON.stringify(wan_stu, null, 2);   // 对象 → 字符串（缩进 2 格）

观察输出：键名自动加上了双引号，单引号字符串变成了双引号——这正是 JSON 的语法要求。
