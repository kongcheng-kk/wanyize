CSS animation 关键帧动画 10-1

过渡只能连接两个状态，动画可以写下任意多个关键帧，还能循环、反向、停在最后一帧。 这一页从那个 300×300 的变色盒子出发，把它拆到每一个子属性。

一条 @keyframes，八个可以调的旋钮

原版作业只有五行关键帧和一句 animation: changeColor 8s infinite linear。 下面把它做成可暂停、可加速、可单次播放的演示，再拆开 animation 的八个子属性逐个验证。

@keyframes animation-duration iteration-count direction fill-mode steps()
01

原版还原：会变色的盒子

8 秒一轮 · 四段颜色

盒子的颜色在 红 → 绿 → 蓝 → 黄 → 红 之间循环。 注意每个关键帧之间颜色是渐变过去的，不是"啪"地换色—— 因为 background 是可插值属性，浏览器会自动补中间色。 下面的进度条读的是动画真实时间，不是另算的估算值。

进度 0% 第 1 轮 当前段 红 → 绿 播放中
当前生效的声明 animation: wan_hue 8s linear infinite;
试试 点「暂停」看进度条停住；切到 0.5× 会明显变慢；选「只跑 1 次」后动画结束会停在起点， 因为默认的 animation-fill-mode: none 不会保留最后一帧。
02

关键帧长什么样

0% 等价于 from，100% 等价于 to 
@keyframes wan_hue {
  0%   { background: #ff4444; }   /* 起点，也可以写 from */
  25%  { background: #44bb44; }
  50%  { background: #3388ff; }
  75%  { background: #ffdd22; }
  100% { background: #ff4444; }   /* 终点，也可以写 to */
}

.wan_colorbox {
  animation: wan_hue 8s linear infinite;
}
0% – 25% 25% – 50% 50% – 75% 75% – 100%
0%25%50%75%100%
规律 百分比是相对于 animation-duration 的。8 秒的动画里，25% 就是第 2 秒。 两个关键帧之间如果没写别的，浏览器就只对两边都出现过的属性做插值。
03

animation 的八个子属性

简写里两个时间：前一个是时长，后一个是延迟
子属性作用默认值本例取值
animation-name用哪一组 @keyframesnonewan_hue
animation-duration一轮跑多久0s（不写就看不到）8s
animation-timing-function每段关键帧之间的速度曲线easelinear
animation-delay推迟多久开始0s0s
animation-iteration-count跑几轮1infinite
animation-direction正着跑、倒着跑还是往返normalnormal
animation-fill-mode动画前后要不要保留关键帧样式nonenone
animation-play-state播放还是暂停runningrunning
简写 animation: wan_hue 8s linear infinite; 里面只有第一个时间是 duration，写第二个时间才是 delay。 多个动画用逗号隔开：animation: spin 3s linear infinite, pulse 1.6s ease-in-out infinite;
04

direction：同一条关键帧，四种跑法

1.8s 一轮

四个方块用的是同一组 @keyframes，只改了 animation-direction。 alternate 的往返是"去程 + 回程"共两轮，所以奇偶轮方向不同， 用来做呼吸灯、钟摆最合适。

normal每到终点就瞬移回起点
reverse从终点往起点跑
alternate去 → 回 → 去，首尾相接
alternate-reverse回 → 去 → 回
重播会把四个方块的相位重新对齐，方便横向对比。
05

steps()：让动画一格一格跳

逐帧动画的关键

默认的动画是连续插值，steps(n) 会把它切成 n 段、每段只取一个值， 于是就有了"帧"的感觉。上面两条同速同距离，下面一条用了 steps(8, end)， 走起来是一跳一跳的。

animation-timing-function: linear2.4s
animation-timing-function: steps(8, end)2.4s
CSS animation 真的一点都不难
打字机 上面这行字没有用 JS，靠的是 clip-path: inset(0 100% 0 0) 从右往左裁掉，再配 steps(24, end) 让它一次露出一个字符的宽度。 光标是另一个动画 wan_blink，两个动画逗号分隔、同时跑。
06

fill-mode：动画前后那段时间算谁的

延迟 1.2s，动画 1s

四个方块都延迟 1.2 秒才开始动，动画本身 1 秒。 灰色是元素的原始样式，黄色是 0% 关键帧，红色是 100% 关键帧。 盯住延迟那 1.2 秒和动画结束之后两个时间点，就能看出四种取值的区别。

none默认，前后都用原始样式
forwards结束后保留最后一帧
backwards延迟期间提前用第一帧
both前后都保留关键帧
重放时四张卡会同时进入 1.2 秒的延迟期，正好对比。
07

和 transition 的分工，以及四个坑

上一页 9-1 讲过渡
对比项transition 过渡animation 动画
状态数量只有起点和终点任意多个关键帧
触发方式必须有属性变化（hover、class）页面加载后自动播放
循环不支持iteration-count: infinite
中途控制只能等它跑完可暂停、反向、跳帧
适合场景按钮反馈、hover 放大加载动画、呼吸灯、逐帧
01只写动画名，不写时长

animation-duration 默认是 0s，只写 animation: wan_hue; 什么都不会发生。时长必须显式给。

02忘了写 infinite

iteration-count 默认是 1，跑完一轮就停。 循环动画记得补上 infinite，否则看起来像"闪了一下就没了"。

03动画会盖住普通样式

动画运行期间，关键帧里的属性优先级高于普通声明，改样式改不动。 调试时先 animation: none，或者用 !important（慎用）。

04无限动画要考虑性能

只动 transform 和 opacity 走合成层，最省。 动 width、left、background 会持续重绘，手机上尤其明显。
