三、实现原理（全部为原生代码）

没有使用任何第三方库，核心就是 async/await + fetch + res.json()：

① fetch 发起请求返回 Promise
② 检查 res.ok404 / 500 手动判断
③ res.json() 解析得到 JS 对象
④ 遍历渲染生成商品卡片
async function wan_load() {
  // 1. 发起请求（fetch 返回 Promise，用 await 等待结果）
  var wan_res = await fetch('https://dummyjson.com/products?limit=8');

  // 2. 404 / 500 不会自动抛错，必须手动检查状态码
  if (!wan_res.ok) {
    throw new Error('HTTP ' + wan_res.status);
  }

  // 3. 把响应体解析成 JSON（同样返回 Promise）
  var wan_data = await wan_res.json();

  // 4. 遍历数组，把每个商品渲染成卡片
  for (var wan_i = 0; wan_i < wan_data.products.length; wan_i++) {
    wan_grid.appendChild(wan_makeCard(wan_data.products[wan_i]));
  }
}

关于跨域：dummyjson.com 的响应头 access-control-allow-origin 会原样返回请求方来源，所以浏览器允许页面直接读取它返回的 JSON——这正是「接口可以跨域访问」的含义。
