Lucide SVG 图标

使用方式：引入 lucide.min.js，页面中写 <i data-lucide="名称"></i>，由 JS 替换为内联 SVG

常用图标（写法：<i data-lucide="home"></i>）

home
user
heart
star
settings
search
cart
camera
music
cloud
bell
flag
book
plane
coffee
smile

不同尺寸（SVG 用 width / height 属性控制）

自定义颜色与描边粗细（SVG 描边属性，字体图标做不到）

颜色：修改 stroke / color 即可
描边粗细：修改 stroke-width，1px / 2px / 3px

动画效果（对 SVG 元素做 CSS 动画）
