18-1 Canvas 动画 · 粒子文字「万逸泽」

高级网页设计 I · 第 18 章 Canvas 图形与动画 —— 用几千个粒子把名字画出来

什么是 Canvas？

<canvas> 是一张可以用 JavaScript 逐帧作画的「位图画布」。它不像 DOM 那样每个元素都是节点，而是像在纸上画画：画完就只是一堆像素。因此它特别适合粒子效果、游戏、图表、签名这类需要大量图形高速重绘的场景。本页的所有动画都由一个 requestAnimationFrame 循环驱动，右下角能看到实时 FPS。

演示粒子聚字 · 万逸泽

01Canvas 使用三步走
任何 canvas 程序都是这三步，本页也一样。
1

拿到画笔（上下文）

canvas 标签本身只是画框，getContext('2d') 返回的 context 对象才是画笔，所有绘制方法都挂在它身上。

2

设定坐标系

画布内部分辨率由 width / height 属性决定，左上角是 (0,0)，y 轴向下。高分屏要乘 devicePixelRatio 才不模糊。

3

循环重绘

每帧先清屏再重画全部内容，用 requestAnimationFrame 驱动，浏览器会在每次刷新前调用回调，比 setInterval 更顺滑省电。

02粒子文字是怎么「拼」出来的
四步：先偷偷画字，再把字变成坐标，最后让粒子追坐标。核心循环就是右侧这段代码。
1

离屏画字

建一个看不见的 canvas，用大号粗体把「万逸泽」画上去——它只是一张黑白位图。

2

采样像素

getImageData() 读出位图数据，每隔 N 个像素检查一次透明度，不透明处记下 (x, y)。

3

粒子追目标

每个粒子记一个目标点，每帧用「弹簧 + 阻尼」把位置往目标拉，就形成了聚拢动画。

核心循环（真实运行的就是它）

const ctx = wan_cvs.getContext('2d');

function wan_loop() {
  ctx.fillStyle = 'rgba(11, 16, 32, .35)';  // 半透明清屏 → 上一帧留下拖影
  ctx.fillRect(0, 0, wan_w, wan_h);

  for (const wan_p of wan_parts) {
    wan_p.vx += (wan_p.tx - wan_p.x) * 0.012;  // 弹簧力：拉向目标点
    wan_p.vy += (wan_p.ty - wan_p.y) * 0.012;
    wan_p.vx *= 0.9; wan_p.vy *= 0.9;        // 阻尼：越飞越慢，防止抖个不停
    wan_p.x  += wan_p.vx; wan_p.y += wan_p.vy;

    ctx.fillStyle = wan_p.color;
    ctx.fillRect(wan_p.x, wan_p.y, 2, 2);      // 画一个小方块粒子
  }
  requestAnimationFrame(wan_loop);           // 预约下一帧，循环往复
}
requestAnimationFrame(wan_loop);
03常用 API 速查表
本页用到 ★ 标记的五个，其余也是 2D 绘制最高频的一批。
API作用本页
getContext('2d')获取 2D 渲染上下文，一切绘制的入口★

04五个必须注意的细节

01高分屏上文字发虚

canvas 的 width 是内部分辨率，CSS 宽度只是显示大小。在 2x 屏上要先把内部分辨率乘 devicePixelRatio，再用 ctx.scale() 缩放画笔，本页已处理。

02不清屏 = 越画越糊

canvas 是持久的像素，上一帧内容不会自动消失。要么 clearRect 干净重画，要么像本页用半透明 fillRect 制造拖影。

03改 width/height 会清空画布

给 cvs.width 赋值（哪怕赋同样的数）会重置整块画布并清空画笔状态，需要重新设置 fillStyle 等属性。

04动画别用 setInterval

setInterval(fn, 16) 与屏幕刷新不同步，容易掉帧撕裂；后台标签页还会继续跑。requestAnimationFrame 自动对齐刷新率并在后台暂停。

05状态要 save / restore

translate、rotate、shadowBlur 这类状态是累积的。进门前 save()，出门 restore()，否则下一张图位置全乱。

✓粒子数量要克制

几千个 fillRect 每帧无压力，但几万个加阴影就会掉帧。用「采样间隔」控制数量——拖动上面的密度滑块就能直观感受。
