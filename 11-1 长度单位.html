一常见长度单位速查表

分类 单位 含义
绝对单位固定值 px 像素，最常用，页面上唯一“所见即所得”的单位
cm / mm / in 厘米 / 毫米 / 英寸（1in = 96px），打印时用
pt 磅，1pt = 1/72 英寸，常用于字体大小
pc 派卡，1pc = 12pt
相对单位随参照物变化 % 相对于【父元素】的对应尺寸
em 相对于【当前元素】的 font-size，会层层相乘
rem 相对于【根元素 html】的 font-size，只算一次
vw / vh 视口（浏览器窗口）宽度 / 高度的 1%
vmin / vmax 视口宽高中【较小 / 较大】者的 1%

二绝对单位：px

固定大小，不随父元素、字体、浏览器窗口变化。

width: 100px; height: 60px
width: 200px; height: 60px

三相对单位：%

百分比相对父元素的对应尺寸计算：父元素宽 600px，子元素 50% 就是 300px。

父元素：max-width 600px
width: 50%
width: 100%

四相对单位：em 与 rem

em 相对当前元素的字号（会层层相乘），rem 只相对根元素 html 的字号（只算一次）。

父元素 font-size: 20px
Aa em
font-size: 2em → 40px
width: 10em → 400px
Aa rem
font-size: 2rem → 32px
width: 20rem → 320px
em 色块：字号 40px，宽度按自身字号算 rem 色块：只按 html 的 16px 算，父元素改成 20px 也不受影响

五视口单位：vw / vh

拖动浏览器窗口大小，下面两个色块会跟着变化。

当前视口：— × — px
width: 50vw（视口宽度的一半）
height: 10vh（视口高度的 10%）

六课堂要点

  • px　用于需要精确控制的固定布局
  • %　用于随父容器伸缩的响应式宽度
  • rem　用于字号与整体缩放（避免 em 层层相乘）
  • vw / vh　用于大屏通栏、整屏高度区块
