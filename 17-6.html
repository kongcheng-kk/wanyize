包饺子里的异步 17-6 🥟

用 Promise 和 async / await 演出包饺子的流程：先买原料，原料到手后 和面、和馅同时开工（Promise.all），两件事都完成才继续包、煮、吃。 点「开始包饺子」，看时间轴怎么走、日志里 Promise 怎么变成 fulfilled。

流程时间轴 并行任务会同时推进

  • 买原料wan_buy() 等待 —

    去超市买面粉、猪肉、白菜 · 前缀任务，必须先完成

  • 和面wan_knead() 等待 —

    面粉加水揉成面团，醒 20 分钟 · 与和馅同时进行

  • 和馅wan_fill() 等待 —

    猪肉剁碎、白菜挤水、调味拌匀 · 与和面同时进行

  • 擀皮 + 包饺子wan_wrap() 等待 —

    等和面、和馅都 fulfilled 之后才轮到这一步

  • 煮饺子wan_boil() 等待 —

    水开下锅，点三次凉水，浮起来就熟

  • 开吃wan_eat() 等待 —

    蘸醋 + 蒜泥，整条异步链结束

    两种写法，同一套流程 高亮的是当前运行的模式

    promise-chain.js
    // 每个步骤都返回一个 Promise
function wan_buy() {
  return new Promise(function (resolve, reject) {
    setTimeout(function () {
      // 面粉卖完就 reject，否则 resolve
      wan_hasFlour ? resolve('面粉 + 猪肉 + 白菜')
                   : reject(new Error('面粉卖完了'));
    }, 650);
  });
}

// 买 → （和面 ∥ 和馅）→ 包 → 煮 → 吃
wan_buy()
  .then(function (mat) {
    // Promise.all：两件事同时做，都完成才继续
    return Promise.all([
      wan_knead(), wan_fill()
    ]);
  })
  .then(function () { return wan_wrap(); })
  .then(function () { return wan_boil(); })
  .then(function () { return wan_eat(); })
  .catch(function (err) {
    // 任何一步 reject 都会跳到这里
    console.error('出错了：', err.message);
  });
    async-await.js
    // async 函数内部用 await，像同步代码一样顺
async function wan_cook() {
  try {
    // 等原料；失败会跳到 catch
    var mat = await wan_buy();

    // 同时等两件事，等价于 Promise.all
    await Promise.all([
      wan_knead(), wan_fill()
    ]);

    await wan_wrap();  // 串行
    await wan_boil();
    await wan_eat();
  } catch (err) {
    console.error('出错了：', err.message);
  }
}

wan_cook();  // async 函数返回的也是 Promise

    关键点：await 会把后面的代码挂起，但不会阻塞页面——等待期间浏览器照样响应点击、播放动画。 所以和面、和馅用 Promise.all([...]) 包起来，两件事才会真的同时开始，而不是一个做完再做另一个。

    Promise 的三种状态 不可逆，只能变一次

    pending 等待中

    刚创建的 Promise，既没成功也没失败。买原料、和面、煮饺子在等待时都处于这个状态。

    new Promise(() => {})

    fulfilled 已兑现

    调用 resolve(值) 之后。状态变成 fulfilled，值交给 .then() 或 await 继续用。

    resolve('面团醒好了')

    rejected 已拒绝

    调用 reject(错误) 或代码抛异常。跳过后面的 then，直接进 .catch() / try…catch。

    reject(new Error('面粉卖完了'))

    为什么一定要 Promise.all 串行 vs 并行

    阶段串行耗时并行耗时说明
    买原料650 ms650 ms必须先做，没有原料什么都干不了
    和面1300 ms1300 ms与和馅同时开始
    和馅1000 ms—被和面“盖住”，不额外占时间
    擀皮 + 包饺子1200 ms1200 ms两件事都完成才能动手
    煮饺子1500 ms1500 ms顺序执行
    开吃400 ms400 ms整条异步链结束
    合计6050 ms5050 ms省下约 1 秒（≈17%）

    另一处容易踩的坑：若写成 await wan_knead(); await wan_fill();，两步会变成串行，总时间回到 6050 ms—— await 只能等，不会自动并行。要并行必须先把两个 Promise 都创建出来，再一起 await。
