18-4 ECharts 箱线图 · 1950 年以来各国收入分布

高级网页设计 I · 第 18 章 图形与可视化 —— 一套 dataset 变换，算出 19 个国家的收入分布

ECharts：用配置对象画图

ECharts 是 Apache 开源的图表库，核心只有一句话：echarts.init(容器).setOption(配置对象)。本页是官方箱线图示例的离线改造版：用 dataset + 三种 transform（filter、aggregate、sort）把 1400 多行原始表格直接算成 min/Q1/median/Q3/max，再画成 19 个国家的箱线图。ECharts、变换插件和 json 数据都已下载到 cdn/echarts/，断网也能打开。

图 1箱线图：1950 年以来各国收入分布
数据源 life-expectancy-table.json（1540 行，19 个国家，1800–2015）。默认只画箱体，红点（每年的原始收入）被图例初始隐藏，可点按钮打开。

读箱线图怎么看

每个国家一条横箱：左须 = 最小值、箱体左边界 = Q1、中间竖线 = 中位数、右边界 = Q3、右须 = 最大值。箱体越短说明该国收入几十年越稳定；箱体越长说明波动越大。颜色深浅来自同一组 q1/median/q3 数据。

算分位数是聚合出来的

原始表只有「某国某年收入」这一列，箱线图需要的 min/Q1/median/Q3/max 是用 ecSimpleTransform:aggregate 按国家分组现算的，不是预先准备好的五个字段。

01ECharts 五步上手
任何 ECharts 页面都逃不出这五步，本页也一样。
1

引入脚本

页面底部加载 echarts.min.js，本例从本地 cdn 目录引入。

2

准备容器

一个 div，必须显式给高度，否则图表高度为 0 看不见。

3

初始化

echarts.init(dom) 返回实例，一个容器只 init 一次。

4

设置配置

setOption(option)，把 dataset、坐标轴、系列一次传进去。

5

跟随尺寸

窗口或容器变化时调用 chart.resize()。

02dataset 三级变换：一张表算出箱线图
图一的精髓不在 series，而在 dataset。原始表只被读进来一次，后面三级变换层层加工，每一步都通过 fromDatasetId 接力。
① raw · 原始表 1540 行 × 5 列（Income / Life Expectancy / Population / Country / Year），第一行是表头。
→
② since_year · 过滤 type: 'filter'，条件 Year ≥ 1950，剩 1254 行。
→
③ income_aggregate · 聚合 ecSimpleTransform:aggregate 按 Country 分组，算 min / Q1 / median / Q3 / max。
→
④ 排序 type: 'sort'，按 Q3 升序，让国家从上到下由穷到富。
原始行数 — 过滤后 1254 国家数 — 年份跨度 1800–2015 
/* 三级 dataset 变换：过滤 → 聚合 → 排序，全部声明式，不写一行循环 */
dataset: [
  { id: 'raw', source: _rawData },
  {
    id: 'since_year', fromDatasetId: 'raw',
    transform: [{ type: 'filter', config: { dimension: 'Year', gte: 1950 } }]
  },
  {
    id: 'income_aggregate', fromDatasetId: 'since_year',
    transform: [
      {
        type: 'ecSimpleTransform:aggregate',
        config: {
          resultDimensions: [
            { name: 'min',    from: 'Income', method: 'min' },
            { name: 'Q1',     from: 'Income', method: 'Q1' },
            { name: 'median', from: 'Income', method: 'median' },
            { name: 'Q3',     from: 'Income', method: 'Q3' },
            { name: 'max',    from: 'Income', method: 'max' },
            { name: 'Country', from: 'Country' }
          ],
          groupBy: 'Country'
        }
      },
      { type: 'sort', config: { dimension: 'Q3', order: 'asc' } }
    ]
  }
]
03series 与 encode：不用手拼数组
有了 dataset，series 只要声明「哪几列画到哪」，箱线图与散点就能各取所需，同一份数据互不干扰。
/* 箱线图：把聚合结果的 5 个分位数列映射到 x，国家映射到 y */
series: [
  {
    name: 'boxplot', type: 'boxplot', datasetId: 'income_aggregate',
    itemStyle: { color: '#b8c5f2' },
    encode: {
      x: ['min', 'Q1', 'median', 'Q3', 'max'],
      y: 'Country',
      itemName: ['Country'],
      tooltip: ['min', 'Q1', 'median', 'Q3', 'max']
    }
  },
  {
    name: 'detail', type: 'scatter', datasetId: 'since_year',
    symbolSize: 6, itemStyle: { color: '#d00000' },
    label: { show: true, position: 'top', rotate: 90, fontSize: 12 },
    encode: { x: 'Income', y: 'Country', label: 'Year', tooltip: ['Country', 'Year', 'Income'] }
  }
],
/* 图例初始把 detail 关掉，所以默认只看到箱体 */
legend: { selected: { detail: false } }
注意图例 selected 只是把散点「隐藏」了，数据依然算好摆在那里；点顶部按钮或点图例里的 detail，1254 个红点立刻出现——这也是常用的「按需展开细节」交互。
05常用 API 与本地资源
API / 配置作用
echarts.init(dom)在容器上创建实例，同一容器重复 init 会警告
setOption(option)设置配置；再次调用默认合并，只传变化部分即可
registerTransform()注册自定义 dataset 变换，本例注册 aggregate
dataset.transfrom声明式数据加工：filter / sort / aggregate，可链式接力
encode声明「哪一列映射到哪个视觉通道」，替代手拼数组
dispatchAction()代码触发交互，如 legendToggleSelect、dataZoom
resize()容器尺寸变化后重算布局，否则图表被裁切或留白
本地文件用途体积
cdn/echarts/echarts.min.jsECharts 5.5.1 主库约 1.0 MB
cdn/echarts/ecSimpleTransform.min.js数据集聚合变换插件（需手动注册）约 5 KB
cdn/echarts/data/life-expectancy-table.json图一数据：1540 行 × 5 列约 58 KB
cdn/echarts/data/life-expectancy-table.js同一份数据的 JS 包装，供本地双击（file://）兜底约 58 KB
06六个容易踩的坑

01容器没有高度

div 默认高度由内容撑开，而图表容器没有内容 → 高度 0 → 白屏。必须写 height: 600px 之类，或用 flex/grid 明确高度。

02插件没加载就 setOption

ecSimpleTransform 不是内置的，且不会自动注册。脚本要在 echarts 之后加载，并在 setOption 前调用 echarts.registerTransform(...)，否则报「找不到 transform」。

03以为图例关掉就没数据

legend.selected.detail = false 只是隐藏系列，数据照常参与布局与 tooltip axis。想彻底移除请删 series。

04第二次 setOption 想去掉旧数据

默认是合并模式，旧的 series / dataset 会残留。要完全替换用 setOption(option, true)（notMerge），或 clear() 后再设。

05窗口缩放图表不跟随

ECharts 不会自动监听尺寸，需要 window.addEventListener('resize', () => chart.resize())；容器布局变化（如折叠面板）用 ResizeObserver。

06CDN 依赖断网就白屏

示例页用 CDN_PATH 拼远程地址，抄下来放进作业往往会加载失败。本页把库、插件、json 全部下载到 cdn/echarts/，用相对路径引用。

为什么还多一个 .js 数据文件？浏览器出于安全限制，双击本地 HTML（file://）时不允许 fetch 本地 json。页面优先走 fetch → json（GitHub Pages 与本地服务器都正常），失败时自动退回 <script> 预载的同源副本，状态栏会写明当前用的是哪一种。
图表做了响应式：窗口宽度变化会调用 resize()；还能用底部的 dataZoom 拖动缩放、滚轮缩放。
