JavaScript 程序结构

顺序结构 · 条件结构 · 循环结构 —— 任何复杂程序都由这三种基本结构组合而成

一、三种基本结构

1966 年 Böhm 与 Jacopini 证明：任何算法都可以只用这三种结构表达，这就是「结构化程序设计」的基础。

顺序结构

自上而下，逐条执行

条件结构

判断真假，选择一条分支

循环结构

条件成立时，重复执行

二、顺序结构

代码从上到下一条一条执行，上一条的结果会被下一条用到。这是默认的执行方式，不需要任何关键字。

示例：三步计算 逐行高亮

var wan_a = 1;                    // 第 1 行
var wan_b = wan_a + 2;          // 第 2 行，用到上一行的结果
var wan_c = wan_a + wan_b;    // 第 3 行，用到前两行的结果
console.log(wan_a, wan_b, wan_c);  // 输出 1 3 4
点击上方按钮，观察代码逐行高亮与结果输出

三、条件结构

先判断条件表达式的真假，再决定执行哪一条分支。同一时刻只会走其中一条路。

1. if / else if / else —— 成绩等级判定 多分支

if (wan_score >= 90) {
  wan_level = "A";
} else if (wan_score >= 80) {
  wan_level = "B";
} else if (wan_score >= 60) {
  wan_level = "C";
} else {
  wan_level = "D";
}

注意：else if 是从上往下依次判断，一旦某个条件成立，后面的分支就不再判断了。

2. switch —— 星期名称 等值匹配

switch (wan_day) {
  case 1: wan_name = "星期一"; break;
  case 2: wan_name = "星期二"; break;
  // …… 一直到 case 7
  default: wan_name = "无效的星期";
}

每个 case 末尾必须写 break，否则会「穿透」继续执行下一个 case。

3. 三元运算符 —— 判断奇偶 简写 if…else

var wan_result = (wan_n % 2 === 0) ? "偶数" : "奇数";

四、循环结构

让同一段代码重复执行，直到条件不再成立。循环由「初始化 → 判断条件 → 执行循环体 → 更新变量」四步组成。

1. for —— 从 1 加到 n 次数已知

var wan_sum = 0;
for (var wan_i = 1; wan_i <= wan_n; wan_i++) {
  wan_sum += wan_i;
}
console.log(wan_sum);

2. while —— 2 的幂序列 次数未知

var wan_v = 1;
while (wan_v <= 1000) {
  wan_v *= 2;   // 1 → 2 → 4 → …… → 1024
}

3. do…while —— 至少执行一次 先执行后判断

var wan_j = 10;
do {
  wan_count++;          // 先执行一次，再去判断条件
} while (wan_j < 5);

4. for…of —— 遍历数组 取值遍历

var wan_fruits = ["苹果", "香蕉", "橙子", "葡萄"];
for (var wan_item of wan_fruits) {
  console.log(wan_item);
}

5. break / continue —— 提前结束与跳过 流程控制

for (var wan_i = 1; wan_i <= 20; wan_i++) {
  if (wan_i > 17) break;               // 超过 17 提前结束整个循环
  if (wan_i % 3 === 0) continue;     // 跳过本次，进入下一次
  wan_list.push(wan_i);
}

6. 嵌套 for —— 九九乘法表 循环套循环

for (var wan_i = 1; wan_i <= 9; wan_i++) {        // 外层：控制行
  for (var wan_j = 1; wan_j <= wan_i; wan_j++) {    // 内层：控制列
    // 输出 wan_j × wan_i = wan_i * wan_j
  }
}

外层循环每走 1 步，内层循环就要完整跑完一遍，所以总执行次数是两层次数相乘。

五、小结

结构 常用关键字 执行特点 典型场景
顺序 （无需关键字） 自上而下逐条执行 赋值、计算、输出
条件 if else if else switch ?: 只走其中一条分支 等级判定、菜单分发、默认值
循环 for while do…while for…of 条件成立就重复执行 累加、遍历、批量生成

三种结构可以任意嵌套：循环里可以写条件（如 break 判断），条件分支里也可以写循环。这正是程序能处理复杂逻辑的原因。
